About the data

  • Source: NOAA Coral Reef Watch (CRW), Version 3.1 daily global 5 km satellite coral bleaching heat stress products, Regional Virtual Stations. Public domain.
  • What it is: satellite-derived sea surface temperature and heat stress indicators that predict bleaching risk. They are not in-water observations of bleaching.
  • Processing: daily station files are downloaded, parsed and summarised (weekly maxima, yearly maxima, alert-level events, linear SST trend over complete years) by a Python pipeline that runs every day on GitHub Actions.
  • Code: github.com/hnryguchi/CoralGuard · built by Henry Noguchi.
